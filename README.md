# 👟 .Sneakers — E-Commerce Website

A modern, responsive sneaker store UI built with HTML & CSS. Clean dark aesthetic with product showcase, size selector, and multi-section layout.

## ✨ Features

- 🖤 Dark hero section with product highlight
- 👟 Product detail page — color picker & size selector
- 🚚 Features bar — Free Shipping, 30 Days Return, Gift Cards
- 🖼️ Editorial photo grid — lifestyle imagery section
- 🌙 New Arrivals dark banner section
- 📬 Newsletter subscription in footer
- 📱 Responsive layout

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/MitaliRakholiya12/sneakers-website.git

# 2. Open in browser
open index.html
```

Or simply download the ZIP and open `index.html` in your browser.
